delivery-eta

배달 예상 시간 API

배달 거리와 밀린 주문 수를 보내면, 고객 화면에 보여 줄 도착 예상 시간을 분 단위로 돌려줍니다.

지금 쓰는 예측기 {{MODEL_IMPL}}

예상 시간 받기 POST /eta

필드형식규칙
distance_km숫자가게에서 배달지까지 거리(km). 0 이상 20 이하
pending_orders정수지금 밀려 있는 주문 수. 0 이상

요청 예시

curl -X POST <이 사이트 주소>/eta \
  -H 'Content-Type: application/json' \
  -d '{"distance_km": 3, "pending_orders": 2}'

응답 예시(규칙 예측기 기준)

{"minutes": 23.0, "model": "rule"}

규칙 예측기는 기본 10분 + 1km당 3분 + 밀린 주문 1건당 2분으로 계산합니다. 범위를 벗어난 값이나 따옴표 친 숫자 "3", true 같은 값은 422 오류로 돌려보냅니다.

상태 확인 GET /health

{"status": "ok", "model": "{{MODEL_IMPL}}"}

서버가 살아 있는지와 지금 쓰는 예측기 이름을 알려 줍니다.
